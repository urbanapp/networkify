The DSL

Each line of the editor describes a node or a connection; the diagram re-renders as you type.

# comments start with # or //
web-01:server                  # a standalone node
web-01 --- db-main:database    # a connection (creates both nodes)
cache                          # type omitted → server
  • The type after : is optional and defaults to server.
  • A node may appear on many lines — the last explicit type wins, duplicate connections are merged.
  • Avoid : and --- inside names; dots and dashes are fine (10.0.0.1, web-01).

Tools & keyboard

V Select — click, drag nodes, Shift+click multi-select
H Hand — pan the grid (Space holds it temporarily)
M Marquee — rectangle select
L Link — drag between nodes to connect
F Fit diagram · T Tidy layout
+/− Zoom · 0 100%
⌫ Delete selected nodes
Esc Cancel link / close panels · Cmd/Ctrl+Z Undo

Mouse

  • Wheel zooms around the cursor; middle-button drag pans with any tool.
  • Right-click or double-click an empty cell to create a node.
  • Right-drag from a node onto another to link them (works with any tool); Alt+drag does the same in Select.
  • Click a node to edit it in the drawer — rename, retype, remove connections.

Import, export & share

  • Import accepts nmap/masscan XML scans, Graphviz DOT (including terraform graph output), networkify JSON exports, and plain DSL text.
  • Drop a file anywhere on the canvas — the import dialog opens with the format detected.
  • Export renders PNG or SVG, or saves JSON (diagram + layout) that you can re-import later.
  • Share copies a link with the whole diagram encoded in the URL; your work also autosaves locally.
